# Plan 09-03: Keyboard-First Session UX + Save/Story Management + Footer Telemetry Polish

**Phase:** 9 — Narrative UX and Input Polish
**Wave:** 2 — controls, discoverability, and metrics
**Requirements:** AI-07, STOR-07, STOR-08, TUI-18, TUI-21, TUI-22

---

## Objective

Make the narrative loop feel better to control from a keyboard and easier to manage at a glance. This wave improves Space/Enter parity, replaces abrupt Esc behavior with a safer in-session menu, adds quick save plus save/story management actions, and expands footer telemetry with clearer labels and cached prompt usage when available.

## Tasks

### Task 1: Add Space/Enter parity across selection UIs
**Files:**
- `internal/tui/components/choicelist.go`
- `internal/tui/views/menu.go`
- `internal/tui/views/loadstory.go`
- `internal/tui/views/saveload.go`

**Action:**
- treat `Space` as confirm/activate wherever `Enter` already means "select this item"
- keep typing-focused text inputs unchanged

**Verify:**
- menu, load story, save picker, and narrative choice list all accept `Space` as confirmation

### Task 2: Replace abrupt narrative Esc with a safer in-session menu
**Files:**
- `internal/tui/app.go`
- `internal/tui/views/narrative.go`
- `internal/tui/components/overlay.go`

**Action:**
- stop mapping narrative `Esc` directly to "close session and jump to menu"
- introduce an in-session menu/overlay with options like resume, save, load, return to main menu
- keep `/quit` available for explicit exit

**Verify:**
- `Esc` no longer throws away the live context without an explicit choice

### Task 3: Add quick save and explicit save/story management actions
**Files:**
- `internal/engine/save.go`
- `internal/storage/saves.go`
- `internal/storage/stories.go`
- `internal/storage/migrations.go`
- `internal/tui/views/narrative.go`
- `internal/tui/views/loadstory.go`
- `internal/tui/views/saveload.go`
- `internal/tui/app.go`

**Action:**
- add a quick-save hotkey during live play
- ensure quick/manual saves create explicit snapshots rather than overwriting named saves
- allow save deletion from the save-management picker
- allow archiving and deleting stories from the load/manage flow

**Verify:**
- quick save creates a new snapshot
- deleting a save removes both its DB record and on-disk snapshot
- archived stories leave the active list by default

### Task 4: Surface clearer telemetry, including cached prompt usage
**Files:**
- `internal/ai/provider.go`
- `internal/ai/providers/openai_compat.go`
- `internal/tui/components/statusbar.go`
- `internal/tui/views/narrative.go`

**Action:**
- extend provider usage parsing to include cached prompt tokens when available
- show cached usage and clearer metric wording in the footer while preserving compactness
- keep timing, throughput, and cost resilient when fields are missing

**Verify:**
- footer still renders cleanly for providers with partial or zero usage metadata
- cached reads become visible when upstream exposes them

### Task 5: Improve save/load discoverability in narrative hints
**Files:**
- `internal/tui/views/narrative.go`

**Action:**

- preserve the terminal-first feel without adding modal clutter all the time

**Verify:**
- a player can infer how to save/load without guessing
