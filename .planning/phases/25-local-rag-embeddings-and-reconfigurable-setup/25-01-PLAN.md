# Plan 25.1: Local Embedding Provider Abstraction

## Objective

Add a real local embedding provider path that supports Ollama and generic/custom local HTTP endpoints without API keys.

## Tasks

1. Extend config with local embedding backend type, base URL, model, and dimensions.
2. Allow `ai.embedding.provider: local` validation only when local fields are complete.
3. Update `aifactory.SelectEmbeddingProvider` to return backend metadata for local providers.
4. Add Ollama `/api/embed` client and custom local HTTP client.
5. Update runtime RAG construction to instantiate the selected local provider.
6. Add unit tests for config validation, selection, and local client parsing/errors.

## Acceptance

- Local embeddings do not require API keys.
- Ollama and custom local HTTP clients satisfy RAG embedder contract.
- Runtime RAG can build with local provider and configured dimensions.
- Remote embedding behavior remains unchanged.
