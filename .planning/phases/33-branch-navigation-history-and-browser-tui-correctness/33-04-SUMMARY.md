# Summary 33.4 — Parity and end-to-end verification

The Go command registry is the parity source consumed by browser contract tests
and TUI dispatch. Playwright covers same-tick duplicate submit, optimistic clear,
stream/challenge lifecycle, failed-draft rollback, branch checkout, history,
search, export, horizontal overflow, and mobile input sizing.

Vitest and Playwright use distinct filename scopes so either runner can execute
without collecting the other framework's tests.
