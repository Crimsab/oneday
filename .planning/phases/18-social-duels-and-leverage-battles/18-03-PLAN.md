# Plan 18.3: Duel UI and Runtime Flow

## Goal

Build the runtime and TUI flow that lets social duels sit naturally between free narrative and full combat.

## Tasks

1. Decide how a social duel starts, pauses the normal narrative loop, and returns control after resolution.
2. Build the TUI affordances for stakes, stance, leverage, round feedback, and available actions without making the mode feel like reskinned combat.
3. Support both keyboard-first choice selection and freeform player intent where appropriate.
4. Ensure duel summaries and aftermath are persisted back into the canonical narrative/history flow.

## Verification

- high-stakes dialogue can cleanly enter and exit duel mode
- the UI communicates stakes and leverage clearly without duplicating combat affordances
- duel aftermath survives resume/history like other major systems
