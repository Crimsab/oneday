# Plan 23.2: Investigation Workspace and Mystery Navigation

## Goal

Turn investigations into a clearer mystery-solving workspace with better structure for clues, suspects, contradictions, leads, and theory state.

## Tasks

1. Design a dedicated investigations view that highlights open cases before solved or quiet ones.
2. Make clue, suspect, contradiction, lead, and theory sections easier to scan than the current codex-first fallback.
3. Preserve uncertainty and hidden-truth safety so the UI helps reasoning without implying the board is omniscient.
4. Add coverage for early-game, single-case, and multi-case mystery flows.

## Verification

- players can reason about active mysteries from one focused workspace
- contradictions, uncertainty, and unresolved leads remain legible
- hidden truths stay hidden while the visible board becomes easier to use
