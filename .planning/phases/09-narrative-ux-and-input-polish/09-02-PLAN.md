# Plan 09-02: Narrative Presentation + Overlay Readability Polish

**Phase:** 9 — Narrative UX and Input Polish
**Wave:** 2 — readability and presentation
**Requirements:** TUI-15, TUI-16, TUI-19, TUI-20

---

## Objective

Make the narrative screen feel intentionally formatted instead of technically functional: dialogue should read like dialogue, relationship/system updates should look like compact game-state callouts, overlays should wrap cleanly, and optional ASCII art should finally be visible when the model emits it.

## Tasks

### Task 1: Render relationship/system updates as readable callout blocks
**Files:**
- `internal/engine/rendering.go`
- `internal/tui/rendering/narrative.go`
- `internal/tui/views/narrative_rendering.go`

**Action:**
- replace the current "single markdown blockquote blob" treatment with compact per-callout blocks
- preserve categories like NPC, relationship, skill, item, location, and system
- keep ordering deterministic and non-spammy

**Verify:**
- relationship/NPC/skill/item updates render as visually separate units instead of one merged paragraph

### Task 2: Upgrade dialogue formatting to speaker + quoted speech styling
**Files:**
- `internal/tui/rendering/narrative.go`
- `internal/tui/views/narrative_rendering.go`
- `internal/tui/components/markdown.go`

**Action:**
- format structured dialogue as `Speaker: "Dialogue"`
- make the speaker label and quoted text visually distinct from plain narration
- keep narrator prose clean and readable
- normalize dialogue text so quotes/newlines do not leak ugly escape sequences

**Verify:**
- NPC speech is immediately recognizable
- narrator prose does not look like chat log output

### Task 3: Surface optional ASCII art safely
**Files:**
- `internal/tui/rendering/narrative.go`
- `internal/tui/views/narrative_rendering.go`

**Action:**
- render optional `ascii_art` when present and reasonably bounded
- avoid breaking the layout with oversized art
- keep absence of art a no-op

**Verify:**
- compact ASCII art appears in the narrative view when supplied
- oversized or empty art is skipped safely

### Task 4: Fix overlay wrapping for `/stats`, relationships, and bios
**Files:**
- `internal/tui/components/overlay.go`
- `internal/tui/views/narrative.go`

**Action:**
- wrap long overlay lines instead of truncating them
- preserve readable formatting for character bio, relationships, skill lines, and help text
- keep scroll behavior correct after wrapping

**Verify:**
- long `/stats` sections no longer get cut mid-word or mid-line

### Task 5: Add renderer/overlay regressions
**Files:**
- `internal/tui/rendering/narrative_test.go`

**Action:**
