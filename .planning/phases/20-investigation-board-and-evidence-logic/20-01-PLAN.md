# Plan 20.1: Canonical Investigation Entities

## Goal

Define the canonical evidence model for mysteries, conspiracies, and theories so investigation state exists as structured world knowledge rather than scattered prose.

## Tasks

1. Define the core investigation entities: clues, suspects, claims, contradictions, leads, theories, and threads.
2. Establish how these entities link to NPCs, factions, places, hooks, and codex entries without duplicating unrelated systems.
3. Persist the board in a way that survives save/load and can be safely explored from multiple UI entry points.
4. Keep hidden truths separate from discovered evidence so the board supports uncertainty instead of omniscience.

## Verification

- mysteries can be represented canonically as structured evidence state
- investigation entities can link to existing world models cleanly
- hidden truths remain hidden until earned
