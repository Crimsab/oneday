# Plan 13.3: Rewind Branches, Downtime, and Crafting QoL

## Goal

Improve player freedom and pacing by making alternate-choice exploration safer, adding intentional downtime beats, and giving crafting more practical guidance.

## Tasks

1. Extend save UX toward branch-friendly rewind semantics so pivotal moments can be revisited without destructive overwrite behavior.
2. Update the save/load interface and metadata model so branch lineage or rewind intent stays understandable in a terminal UI.
3. Introduce downtime-scene support for rest, training, campfire, letters, markets, confessions, and other low-intensity moments that deepen attachment to the run.
4. Improve crafting guidance with actionable answers such as what can be crafted now, material tagging, recipe similarity/discovery hints, and post-failure suggestions.
5. Add regression tests around branch-save metadata, rewind safety, and the new crafting helper behaviors.

## Verification

- players can preserve and revisit alternate paths without feeling they are breaking the run
- save/load UI can communicate rewind branches clearly enough in terminal form
- downtime scenes feel like deliberate breathing room rather than filler
- crafting offers practical next-step guidance instead of only pass/fail narration
