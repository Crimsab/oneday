# Plan 3.3: Chat Commands — /inventory, /stats, /save, /load, /help, /quit

## Objective

Implement the slash command system for Phase 3. Players type `/command` in the free input area during gameplay. Commands are intercepted before being sent to the AI, parsed, and executed locally. This plan covers the 6 commands required by CMD-01: `/inventory` (`/i`), `/stats` (`/s`), `/save`, `/load`, `/help` (`/h`), `/quit` (`/q`).

## must_haves

- Commands are prefixed with `/` and intercepted before AI processing
- Each command has a short alias: `/i`, `/s`, `/h`, `/q`
- `/inventory` displays the character's inventory (equipped + backpack + quest items)
- `/stats` displays the character sheet (vitals, attributes, secondary, traits, skills, titles)
- `/save` creates a named manual save
- `/load` shows a list of saves and restores the selected one
- `/help` lists all available commands with descriptions
- `/quit` saves and exits to main menu
- Unknown commands show an error message
- Commands do not count as turns and are not sent to the AI

Create `internal/engine/commands.go` with:

```go
// Command represents a parsed chat command.
type Command struct {
    Name string   // e.g. "inventory", "stats", "save", "load", "help", "quit"
    Args []string // arguments after the command name
}

// CommandRegistry maps command names (including aliases) to canonical names.
var CommandRegistry = map[string]string{
    "inventory": "inventory",
    "i":         "inventory",
    "stats":     "stats",
    "s":         "stats",
    "save":      "save",
    "load":      "load",
    "help":      "help",
    "h":         "help",
    "quit":      "quit",
    "q":         "quit",
}

// ParseCommand checks if input is a command (starts with "/").
// Returns nil if not a command.
func ParseCommand(input string) *Command

// IsCommand returns true if the input starts with "/".
func IsCommand(input string) bool
```

**ParseCommand logic:**
1. Trim whitespace from input.
2. If doesn't start with `/`, return nil.
3. Strip leading `/`, split by whitespace.
4. First token is the command name (lowercase).
5. Look up in `CommandRegistry` for canonical name.
6. If not found, return `Command{Name: "unknown", Args: []string{original}}`.
7. Remaining tokens are `Args`.
</action>

<acceptance_criteria>
- `ParseCommand("/inventory")` returns `&Command{Name: "inventory"}`
- `ParseCommand("/i")` returns `&Command{Name: "inventory"}`
- `ParseCommand("/save My Save")` returns `&Command{Name: "save", Args: ["My", "Save"]}`
- `ParseCommand("attack the goblin")` returns nil
- `ParseCommand("/unknown")` returns `&Command{Name: "unknown"}`
</acceptance_criteria>

### Task 2: Intercept commands in narrative view

<read_first>
- internal/tui/views/narrative.go (Update handler — enter key, sendAction)
</read_first>

<action>
**Modify `internal/tui/views/narrative.go` — the enter key handler in `Update`:**

Before calling `sendAction(text)`, check `engine.IsCommand(text)`. If it is a command:

1. Parse with `engine.ParseCommand(text)`.
2. Do NOT call `sendAction`.
3. Instead, dispatch to a `handleCommand(cmd *engine.Command)` method that returns `(NarrativeModel, tea.Cmd)`.
4. Clear the input field.

```go
case "enter":
    if m.inputFocus {
        text := strings.TrimSpace(m.input.Value())
        if text == "" {
            return m, nil
        }
        m.input.Reset()
        if engine.IsCommand(text) {
            cmd := engine.ParseCommand(text)
            return m.handleCommand(cmd)
        }
        return m, m.sendAction(text)
    }
```

Add `handleCommand` method:

```go
func (m *NarrativeModel) handleCommand(cmd *engine.Command) (NarrativeModel, tea.Cmd) {
    switch cmd.Name {
    case "inventory":
        return m.showInventory()
    case "stats":
        return m.showStats()
    case "save":
        return m.doSave(cmd.Args)
    case "load":
        return m.doLoad()
    case "help":
        return m.showHelp()
    case "quit":
        return m.doQuit()
    default:
        m.errMsg = fmt.Sprintf("Unknown command: /%s. Type /help for available commands.", cmd.Args[0])
        return *m, nil
    }
}
```
</action>

<acceptance_criteria>
- Typing `/help` and pressing Enter does NOT send to AI
- Command is parsed and dispatched to the correct handler
- Unknown commands show an error message
- Normal text is still sent to AI as before
</acceptance_criteria>

```go
func (m *NarrativeModel) doSave(args []string) (NarrativeModel, tea.Cmd) {
    saveName := "Manual Save"
    if len(args) > 0 {
        saveName = strings.Join(args, " ")
    }
    // Fire async save
    return *m, func() tea.Msg {
        _, err := engine.SaveGame(
            m.narrator.DB(), m.narrator.DataDir(),
            m.narrator.Story(), m.narrator.Character(), m.narrator.World(),
            m.narrator.SessionID(), saveName,
        )
        return SaveCompleteMsg{Name: saveName, Err: err}
    }
}
```

Handle `SaveCompleteMsg` in Update to show "Game saved: {name}" in overlay or status bar.

**`/load` implementation:**

1. Fetch `ListSaves(db, storyID)`.
2. If no saves, show "No saves found."
3. Otherwise, switch to a save selection sub-view (or overlay).

```go
func (m *NarrativeModel) doQuit() (NarrativeModel, tea.Cmd) {
    // Trigger autosave then quit
    return *m, func() tea.Msg {
        _ = engine.Autosave(
            m.narrator.DB(), m.narrator.DataDir(),
            m.narrator.Story(), m.narrator.Character(), m.narrator.World(),
            m.narrator.SessionID(),
        )
        m.narrator.CloseSession()
        return QuitToMenuMsg{}
    }
}

// QuitToMenuMsg signals the app to return to the main menu.
```
