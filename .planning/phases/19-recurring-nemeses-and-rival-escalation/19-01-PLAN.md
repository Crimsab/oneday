# Plan 19.1: Nemesis Promotion and Canonical Rival State

## Goal

Define when a recurring rival becomes a true nemesis and persist the state needed to make that promotion matter.

## Tasks

1. Identify promotion triggers such as escapes, repeated conflict, humiliation, political fallout, betrayals, or major wounds.
2. Define a nemesis profile covering scars, vows, remembered patterns, escalation tier, last outcome, and active threat posture.
3. Persist nemesis state in a way that survives save/load, rewind, and codex/dossier browsing.
4. Ensure non-nemesis rivals remain possible without forcing every recurring NPC into the same escalation track.

## Verification

- nemesis promotion follows explicit rules instead of ad-hoc prose repetition
- nemesis profiles survive persistence and are separate from generic NPC state
- the system supports both promoted nemeses and ordinary recurring rivals
