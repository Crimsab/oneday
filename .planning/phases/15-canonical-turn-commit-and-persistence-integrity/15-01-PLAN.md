# Plan 15.1: Canonical Turn Commit Contract

## Goal

Define and enforce a single canonical turn-commit contract so narrative turns cannot partially advance world state, session counters, and history out of sync.

## Tasks

1. Audit every turn-producing runtime path that mutates canonical story state, including the main narrative loop, challenge continuations, combat/crafting aftermath, and save-triggered turn edges.
2. Define one engine-owned commit contract that applies state, persists canonical records, advances turn ownership, and reports failure semantics in a single ordered flow.
3. Refactor narrator/session code so `world.CurrentTurn`, `session.turn`, and canonical history are derived from a successful commit rather than optimistic pre-write updates.
4. Document the invariants for canonical turn ownership and keep non-turn meta flows such as `/narrator` and history-only events explicitly outside that contract.

## Verification

- a normal narrative turn cannot leave `world.CurrentTurn`, `session.turn`, and canonical history disagreeing
- turn advancement happens only after the canonical commit path succeeds
- non-turn meta interactions remain readable and persisted without impersonating a real committed turn
