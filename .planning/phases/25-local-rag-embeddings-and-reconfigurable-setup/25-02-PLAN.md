# Plan 25.2: Reconfigurable Setup Wizard and Model Selection

## Objective

Make setup re-runnable with explicit intent and add model-backed RAG choices: no RAG, remote embeddings, Ollama local embeddings, or custom local endpoint.

## Tasks

1. Add `setup --force` and `setup --reconfigure` handling.
2. Preserve existing `config.yaml` by default and print clear reconfigure instructions.
3. Present local model choices with concise trade-offs and dimension defaults.
4. Implement Ollama setup helper: detect CLI, optionally run install guidance, optionally pull selected model, smoke-test `/api/embed`.
5. Implement custom local setup helper: prompt for URL/model/dimensions and smoke-test.
6. Refactor setup config mapping into testable helpers and cover all setup branches.

## Acceptance

- Running `oneday setup` with existing config explains how to reconfigure.
- Running `oneday setup --force` reopens choices.
- Local RAG config validates for Ollama and custom endpoint.
- Setup can smoke-test local embeddings before writing config.
