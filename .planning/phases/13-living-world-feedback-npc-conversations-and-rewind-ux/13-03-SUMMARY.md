# Summary 13.3: Rewind Branches, Downtime, and Crafting QoL

Save snapshots now carry branch-aware metadata so a run continued from an earlier load can advertise itself as a rewind branch instead of looking like a destructive overwrite. Manual, quick, and auto saves all preserve that metadata, and the save picker surfaces the branch label inline.

Added `/downtime` as an explicit low-intensity scene request, plus practical crafting QoL in the sidebar: material lists, material tags, craftable-known recipes, near-miss recipes, and failure alternatives/missing-material hints.
