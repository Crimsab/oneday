# Plan 28.1: Versioned Snapshot Envelope and Validator

## Objective

Replace the `Story != nil` completeness shortcut with a versioned, checksummed
snapshot envelope and a deterministic validation result used by save and load.

## Tasks

1. Write failing storage tests for version/checksum/manifest validation, identity mismatches, omitted required collections, and tampered payloads.
2. Extend `SaveSnapshot` with backward-compatible format, manifest, and checksum metadata plus canonical serialization/checksum helpers.
3. Make `SaveGame` emit the current full format only after all required aggregates and identities are collected.
4. Replace `HasFullRollbackState` internals with strict validation while retaining a compatibility wrapper for callers.
5. Expand the engine round-trip fixture to compare all snapshot-backed NPC/story/world/session fields, not only selected values.

## Acceptance

- SNAP-01, SNAP-02, and SNAP-03 have observable tests through storage validation and public save/load.
- Tampering with any covered canonical field invalidates the checksum.
- Old snapshot JSON still unmarshals and is classified rather than crashing.
