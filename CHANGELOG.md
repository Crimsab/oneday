## [0.1.0](https://github.com/Crimsab/oneday/releases/tag/v0.1.0) (2026-08-01)

First public pre-stable release of OneDay.

### Highlights

- Persistent AI stories across browser, PWA, terminal, and desktop clients.
- Guided local or remote setup with protected browser sessions.
- Codex OAuth and Claude Code subscription support, plus LiteLLM-compatible and
  OpenRouter API providers.
- Codex defaults to `gpt-5.6-luna` with low reasoning on new installations.
- Image generation, visual continuity, maps, asset revisions, and annotations.
- Signed desktop updates and installers for Windows, Linux, and macOS.
- Import, export, backup, recovery diagnostics, and accessibility coverage.

The earlier `1.x` and `0.19.0` versions were experimental development builds.
They are retired from GitHub Releases. Their source history remains available in
Git, but they are not part of the supported public release line.
