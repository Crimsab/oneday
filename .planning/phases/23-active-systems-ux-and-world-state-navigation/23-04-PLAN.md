# Plan 23.4: Active Systems Navigation and Change Callouts

## Goal

Unify the way players move between projects, investigations, fronts, codex, and live fallout so system changes feel immediate and connected.

## Tasks

1. Design a clear navigation flow between the new dedicated system views and the existing codex/dossier surfaces.
2. Add concise player-facing callouts for important system changes such as front escalation, project completion, or investigation breakthroughs.
3. Make sure these surfaces can cross-link into one another instead of trapping the player inside isolated views.
4. Add integration coverage for transitions between active systems during live play.

## Verification

- players can move between active systems without memorizing disconnected commands
- important world-state changes get readable callouts at the moment they matter
- the dedicated system views and codex surfaces reinforce each other instead of competing
