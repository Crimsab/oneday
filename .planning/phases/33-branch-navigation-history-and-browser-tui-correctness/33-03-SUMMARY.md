# Summary 33.3 — Narrative readers and responsive UX

Structured narrator dialogue now renders accessible speaker blocks keyed by
canonical speaker IDs while retaining prose fallback. A dedicated history reader
loads branch-scoped messages and chapters, supports search and older-page loads,
and downloads Markdown or JSON exports.

Relationship presentation uses the engine/TUI `-100..100` scale. Responsive
layout gives mobile pages one scroll owner, opens hidden modules in a drawer,
keeps controls within the viewport, uses 16 px form text, and removes misleading
NPC/faction labels.
