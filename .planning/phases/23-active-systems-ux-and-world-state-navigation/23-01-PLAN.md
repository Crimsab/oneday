# Plan 23.1: Dedicated Project Workspace

## Goal

Give active and completed projects their own first-class TUI surface so players can understand long-arc progress, stakes, rewards, and linked fallout without digging through generic codex browsing.

## Tasks

1. Design a dedicated projects view that clearly separates active, paused, and completed projects.
2. Surface progress clocks, stakes, owners, locations, rewards, and linked fronts/NPCs in a scannable layout.
3. Keep the projects workspace fast to open from live play and consistent with existing TUI interaction patterns.
4. Add focused coverage for empty-state, single-project, and mixed active/completed project flows.

## Verification

- players can inspect projects as a dedicated system view instead of a generic codex slice
- progress, stakes, and durable outcomes are readable at a glance
- project navigation still feels native to the current TUI flow
