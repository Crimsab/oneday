**Wave:** 1 — Core systems

## Context

### What exists
- `storage.Achievement` model with `Name`, `Description`, `Category`, `Rarity`, `Context`, `EarnedAt` fields (`internal/storage/models.go:100-110`)
- `storage.DB.CreateAchievement()` and `ListAchievements()` CRUD (`internal/storage/achievements.go`)
- `engine.NarrativeResponse` has an `Achievements` field (currently unused — Phase 7 placeholder) (`internal/engine/types.go:94`)
- `ai.NarrativeResponse` has `AchievementEarned string` field (`internal/ai/response.go:21`) — only a string, needs to become a struct
- `docs/achievement_rules.md` — full rules doc for AI with categories, rarities, output format
- AI narrator prompt has `"achievements": []` in the JSON format spec (`internal/ai/prompts/narrator.go:57`)
- `/achievements` command shows overlay via `engine.FormatAchievementsView()` (`internal/engine/journal.go:42`)
- `components.OverlayModel` — generic dismissable overlay component (`internal/tui/components/overlay.go`)
- `theme/theme.go` — static Lipgloss styles with hardcoded RPG palette colors
- `engine.Narrator.sendTurn()` — processes AI response, applies state changes, but does NOT process achievements (`internal/engine/narrator.go:201-392`)
- AI response comment at line 303: "Achievements are kept in the response type but will be consumed in Phase 7 (achievement engine)"

### What's missing
1. Achievement engine: parse `achievement_earned` from AI, validate (no duplicates, valid category/rarity), persist, emit TUI message
2. Achievement notification popup (TUI-08): a brief rarity-colored notification distinct from the generic overlay
3. Achievement rules injected into AI context so the AI actually knows when/how to award
4. Mood theming (TUI-09): narrative mood dynamically changes accent colors, borders, status bar

### Task 4: Achievement validation and persistence in narrator
**File:** `internal/engine/achievements.go` (new file)
**Action:** Create the achievement engine:
```go
// ValidateAndPersistAchievement checks the AI-returned achievement data,
// validates category/rarity, checks for duplicates, and persists to DB.
// Returns the persisted Achievement or nil if invalid/duplicate.
func ValidateAndPersistAchievement(db *storage.DB, storyID string, data *AchievementData) *storage.Achievement
```
Validation rules:
- `data` must not be nil
- `Name` must be non-empty
- `Category` must be one of: story, combat, social, exploration, skill, creative, meta
- `Rarity` must be one of: common, uncommon, rare, epic, legendary
- Check `db.ListAchievements(storyID)` for duplicate names (case-insensitive)
- If valid, call `db.CreateAchievement()` and return the result

**File:** `internal/engine/narrator.go`
**Action:** In `sendTurn()`, after parsing `narrative` and applying state changes, add:
```go
if narrative.AchievementEarned != nil {
    persisted := ValidateAndPersistAchievement(n.db, n.story.ID, narrative.AchievementEarned)
    if persisted != nil {
        narrative.PersistedAchievement = persisted // new field for TUI consumption
    }
}
```
Add `PersistedAchievement *storage.Achievement` to `NarrativeResponse` (not serialized to JSON — TUI-only field).

**Verify:** `go build ./...` compiles. Play turns — when AI awards an achievement, it should appear in the DB (check via `/achievements` command).

### Task 5: Achievement notification popup component (TUI-08)
**File:** `internal/tui/components/achievement_popup.go` (new file)
**Action:** Create `AchievementPopupModel` — a brief notification that appears when an achievement is earned. Distinct from the generic overlay:
- Smaller than overlay (fixed width ~50 chars, ~6-8 lines tall)
- Centered horizontally, positioned at top-third of screen
- Rarity-colored border and title:
  - common: `#A0A0A0` (silver)
  - uncommon: `#4CAF50` (green)
  - rare: `#2196F3` (blue)
  - epic: `#9C27B0` (purple)
  - legendary: `#FFD700` (gold, with bold)
- Content layout:
  ```
  ╭──────────────────────────╮
  │  ★ ACHIEVEMENT UNLOCKED  │
  │  ─────────────────────── │
  │  "Il Diplomatico"        │
  │  Hai convinto il Lupo... │
  │  [epic · social]         │
  │                          │
  │  Press any key...        │
  ╰──────────────────────────╯
  ```
- Auto-dismiss after 5 seconds OR on any keypress (whichever comes first)
- Emits `AchievementDismissedMsg` on close

Interface:
```go
type AchievementPopupModel struct { ... }
func NewAchievementPopup() AchievementPopupModel
func (m *AchievementPopupModel) Show(name, description, rarity, category string)
func (m AchievementPopupModel) Update(msg tea.Msg) (AchievementPopupModel, tea.Cmd)
func (m AchievementPopupModel) View() string
func (m AchievementPopupModel) Visible() bool
func (m *AchievementPopupModel) SetSize(w, h int)
```

**File:** `internal/tui/theme/theme.go`
**Action:** Add rarity color constants:
```go
var (
    RarityCommon    = lipgloss.Color("#A0A0A0")
    RarityUncommon  = lipgloss.Color("#4CAF50")
    RarityRare      = lipgloss.Color("#2196F3")
    RarityEpic      = lipgloss.Color("#9C27B0")
    RarityLegendary = lipgloss.Color("#FFD700")
)
```
Add a helper `RarityColor(rarity string) lipgloss.Color` that maps string to color.

**Verify:** Component compiles. Visual check deferred to integration (Task in Wave 2).
