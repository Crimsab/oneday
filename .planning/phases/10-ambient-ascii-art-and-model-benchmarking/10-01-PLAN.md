# Plan 10.1: Ambient ASCII Cue Pipeline

## Goal

Move ambient ASCII art from an opportunistic inline field into a structured, same-turn enhancement pipeline.

## Tasks

1. Add `ascii_cue` to the narrative response contract, response schema, persistence metadata, and engine types.
2. Add prompt instructions that explain exactly when ASCII cues are allowed:
   - first reveal of an important location
   - chapter opener / major scene transition
   - signage, terminals, maps, ritual circles, altars, iconic objects
   - never for routine dialogue or every ordinary turn
3. Add a dedicated ASCII-art prompt builder that takes only the minimal scene context needed for art generation.
4. Trigger a second AI call when `ascii_cue` is present, then patch the resulting ASCII art into the current scene instead of advancing to a new turn.
5. Persist cue/art metadata for resume/load and keep fallback behavior safe when the art call fails or returns unusable output.
6. Add focused tests for cue parsing, normalization, and same-turn rendering behavior.

## Verification

- narrative JSON can parse with and without `ascii_cue`
- a scene with a cue can display ASCII art in the same turn
- a failed art call does not break the turn or replace narrative text
- resume/load preserves the most recent art/cue metadata when it exists
