# Summary 33.2 — Browser correctness

Added an accessible branch navigator and shared slash-command behavior for
`/branches`, `/fork`, `/branch-rename`, and `/checkout`. Composer submission now
clears optimistically, rejects same-tick duplicates, and restores a failed draft
only while the player has not typed replacement text.

Browser status, time, weather, condition, quick facts, and message labels now
consume typed canonical values or explicitly report that a fact is untracked.
Player-facing turn progress replaces operator-oriented “Live engine” wording.
