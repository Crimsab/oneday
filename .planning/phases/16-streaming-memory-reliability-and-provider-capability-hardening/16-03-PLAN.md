# Plan 16.3: Embedding Capability Selection

## Goal

Make embedding-provider selection explicit, deterministic, and capability-aware instead of loosely following whichever provider happens to be enabled first.

## Tasks

1. Define the config contract for embeddings, including an explicit provider choice and a safe `auto` mode.
2. Add capability-aware provider probing or declaration so embedding selection reflects real `/embeddings` support instead of generic chat availability.
3. Surface clear diagnostics when embeddings are disabled or unavailable, and ensure the rest of the game degrades safely without silent drift.
4. Add tests for explicit provider forcing, auto selection, and no-capable-provider failure modes.

## Verification

- embedding-provider selection obeys explicit config or deterministic auto mode
- RAG does not silently bind itself to an embedding-incompatible provider
- failure to provide embeddings is diagnosable without breaking core play
