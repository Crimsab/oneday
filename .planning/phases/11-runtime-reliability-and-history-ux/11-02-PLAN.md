# Plan 11.2: Narrative Interaction and Rendering Polish

## Goal

Tighten the live interaction feel so navigating choices, reading dense scenes, and understanding narrative metadata all feel deliberate and readable.

## Tasks

1. Decouple choice navigation from viewport scrolling, and enable mouse-wheel scrolling only for the narrative viewport.
2. Strengthen trusted entity rendering for locations/world names/factions/NPCs with role-aware emphasis that is more readable than generic bold text.
3. Render dialogue and relationship/system updates as more compact, structured blocks that stay readable during dense turns.
4. Improve choice inspect/help so semantic badges and legacy choices produce useful explanations instead of a dead-end fallback.
5. Add visible quick-save confirmation and improve status-line behavior on narrower terminals.

## Verification

- pressing up/down on choices does not scroll the chat viewport
- mouse wheel scrolls the narrative area without affecting choice selection
- trusted locations/NPC names are easier to spot in live play
- dialogue and relationship/system updates render as clearly separated blocks
- quick-save feedback and footer telemetry remain readable in smaller terminals
