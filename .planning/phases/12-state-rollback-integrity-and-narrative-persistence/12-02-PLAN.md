# Plan 12.2: Canonical Narrative Persistence

## Goal

Ensure all important narrative-side systems write into the canonical story history so resume, history, and long-term memory remain coherent.

## Tasks

1. Add a schema migration that allows the message types the engine already emits for narrator-meta turns and combat summaries.
2. Make `/narrator` persistence fail-safe instead of silently dropping inserts.
3. Route combat outcome summaries through the canonical append path so they are present in DB history and downstream RAG/history consumers.
4. Update history rendering labels so the newly persisted entries stay readable in the overlay.

## Verification

- `/narrator` entries are visible in `chat_messages` and `/history`
- combat summaries survive reload/resume and appear in the canonical timeline
- no insert failures are ignored for supported message types
