# Plan 15.2: Canonical DB Authority and JSONL Mirror Safety

## Goal

Make canonical DB persistence authoritative and demote JSONL/session files to a derived mirror so mirror failures can no longer corrupt continuity.

## Tasks

1. Decide and codify which persistence surfaces are canonical versus mirrored, with SQLite-backed story/session history as the authority and JSONL/session files treated as secondary logs.
2. Route turn commits through the canonical DB path first, then write or update any mirror/session artifacts only after the authoritative commit succeeds.
3. Add degraded-mode behavior for mirror failures so the game can continue safely while surfacing that the JSONL/session mirror needs backfill or repair.
4. Ensure autosave, rollback, and history readers consume canonical state correctly even when mirror files are missing, stale, or partially written.

## Verification

- JSONL/session-file write failures do not corrupt or renumber canonical turns
- resume/history can still reconstruct the story from canonical data when mirrors are stale or absent
- autosave and rollback continue to operate coherently when mirrors lag behind
