# Requirements: OneDay

**Defined:** 2026-04-07
**Core Value:** The player can start a story and have an engaging, coherent, infinite narrative experience driven by AI.

## v1 Requirements

### Core Engine

- [ ] **CORE-01**: Player can create a new story through AI-guided conversation that builds setting, rules, and stats schema
- [ ] **CORE-02**: Player can choose protagonist name and optional background at story start
- [ ] **CORE-03**: Narrative loop works: player input → AI context building → AI response → state update → TUI render
- [ ] **CORE-04**: Player always has a free action input alongside AI-suggested choices
- [ ] **CORE-05**: Story state (protagonist, NPCs, world) persists to disk and can be loaded
- [ ] **CORE-06**: Autosave triggers every N turns; manual save/load available

### AI Integration

- [ ] **AI-01**: AI provider router supports Claude Code CLI, LiteLLM, and OpenRouter with configurable fallback chain
- [ ] **AI-02**: AI responses are structured JSON (narrative, choices, state_changes, mood, challenges, achievements)
- [ ] **AI-03**: AI responses stream to TUI with typewriter effect
- [ ] **AI-04**: Context builder assembles system prompt + recent chat + player state + NPC state + RAG chunks
- [ ] **AI-05**: AI model and response latency shown in status bar

### Character System

- [ ] **CHAR-01**: Character starts with minimal stats defined by story schema (near-zero attributes, no traits, no skills)
- [ ] **CHAR-02**: Attributes grow through use (AI suggests +1 at natural moments)
- [ ] **CHAR-03**: Traits emerge from player behavior patterns (AI assigns after repeated choices)
- [ ] **CHAR-04**: Skills are learned by doing, with levels and XP
- [ ] **CHAR-05**: Titles are earned through notable deeds (AI awards narratively)
- [ ] **CHAR-06**: Character sheet viewable via /stats command

### NPC System

- [ ] **NPC-01**: NPCs are generated by AI when first encountered (not pre-defined)
- [ ] **NPC-02**: Each NPC has personality traits, speech style, quirks, values, fears
- [ ] **NPC-03**: NPCs have private thoughts and notes about protagonist (hidden from player, used by AI)
- [ ] **NPC-04**: NPCs have optional desires (hidden motivations that drive behavior)
- [ ] **NPC-05**: NPC disposition (-100 to +100) tracks relationship and affects interactions
- [ ] **NPC-06**: NPCs can be allies/helpers narratively (not mechanically controlled)

### Storage and Persistence

- [ ] **STOR-01**: SQLite database stores all game data (stories, characters, NPCs, world state)
- [ ] **STOR-02**: Chat history saved as JSONL per session, organized by session > chapter
- [ ] **STOR-03**: Sessions auto-created when player opens a story, closed on exit
- [ ] **STOR-04**: Separate chat logs for combat, crafting, and deep NPC dialogues
- [ ] **STOR-05**: Chapter system with AI-generated summaries at chapter boundaries

### RAG

- [ ] **RAG-01**: Periodic summarization (every N turns) generates text chunks
- [ ] **RAG-02**: Chunks embedded via text-embedding-3-small through LiteLLM
- [ ] **RAG-03**: Embeddings stored in sqlite-vec per story
- [ ] **RAG-04**: Context builder retrieves top-K relevant chunks for AI prompts

### Combat

- [ ] **COMBAT-01**: Turn-based combat with separate chat session
- [ ] **COMBAT-02**: Enemy stats and behavior patterns generated by AI
- [ ] **COMBAT-03**: Damage calculated by engine (stats + dice roll + modifiers), not AI
- [ ] **COMBAT-04**: Player can always type free actions (talk, flee, creative solutions)
- [ ] **COMBAT-05**: Defeat outcome decided by AI based on context (death, capture, rescue, retreat, etc.)
- [ ] **COMBAT-06**: Combat summary written to main narrative after resolution

### Challenges

- [ ] **CHAL-01**: Stat checks — passive threshold checks resolved by engine
- [ ] **CHAL-02**: Dice rolls — active rolls with modifiers, animated in TUI, resolved by engine
- [ ] **CHAL-03**: Item/skill/relationship checks — require specific items, skills, or NPC disposition
- [ ] **CHAL-04**: Mini-games: rock-paper-scissors, memory sequences, quick-time events, riddles

### Crafting

- [ ] **CRAFT-01**: Crafting is a conversation with AI in separate chat session
- [ ] **CRAFT-02**: AI evaluates feasibility based on inventory, world rules, and skills
- [ ] **CRAFT-03**: Items have narrative effects (not numerical stats)
- [ ] **CRAFT-04**: Discovered recipes saved to character's known_recipes

### Achievements

- [ ] **ACH-01**: No predefined achievements — AI recognizes noteworthy moments using rules doc
- [ ] **ACH-02**: Achievement categories: story, combat, social, exploration, skill, creative, meta
- [ ] **ACH-03**: Achievements are per-story, shown with TUI notification
- [ ] **ACH-04**: Achievement rarity: common, uncommon, rare, epic, legendary

### TUI

- [ ] **TUI-01**: Main menu with new story, load story, settings, quit
- [ ] **TUI-02**: Narrative view with chapter/location header, narrative text, choices + free input, status bar
- [ ] **TUI-03**: Status bar shows vitals, AI model, and response latency
- [ ] **TUI-04**: Combat view with HP bars, turn info, choices + free input
- [ ] **TUI-05**: Crafting view with inventory display and conversation
- [ ] **TUI-06**: Character sheet view (stats, attributes, skills, titles, traits, relationships)
- [ ] **TUI-07**: Inventory view
- [ ] **TUI-08**: Achievement notification popup
- [ ] **TUI-09**: Mood-based theming (Lipgloss styles change with narrative mood/genre)

### Chat Commands

- [ ] **CMD-01**: /inventory, /stats, /save, /load, /help, /quit
- [ ] **CMD-02**: /map, /journal, /achievements
- [ ] **CMD-03**: /narrator (/n) — meta-level world-building, lore injection, NPC depth, narrative steering
- [ ] **CMD-04**: /narrator changes auto-update story.json, NPC files, world_state

### Dynamic World

- [ ] **WORLD-01**: story.json is a living document — factions, cultures, dangers, rules auto-updated
- [ ] **WORLD-02**: NPCs' private thoughts, desires, notes evolve as the story progresses
- [ ] **WORLD-03**: World state tracks unlocked locations, global events, faction standings

### Configuration

- [ ] **CONF-01**: Global config.yaml for AI providers, endpoints, keys, game settings
- [ ] **CONF-02**: AI provider priority chain configurable (Claude Code → LiteLLM → OpenRouter)

## v2 Requirements

### Plugin System

- **PLUG-01**: Custom stories via JSON/YAML
- **PLUG-02**: Lua scripting via gopher-lua for game event hooks
- **PLUG-03**: Plugin discovery and loading from plugins/ directory

### Advanced Features

- **ADV-01**: Story branching visualization (decision tree)
- **ADV-02**: ASCII world map generated as locations discovered
- **ADV-03**: Story export as markdown/epub
- **ADV-04**: Undo/rewind (go back N turns, branch story)
- **ADV-05**: Cross-compilation CI (Windows, Linux, macOS binaries)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Multiplayer | Personal single-player experience |
| Web UI | TUI-only, terminal is the medium |
| Pre-generated content | Everything AI-generated at runtime |
| Hardcoded recipes/achievements/stats | All dynamic by design |
| Psyche integration | Removed from scope |
| Companion combat system | NPCs help narratively, not mechanically |
| AI history log file | Only latency in statusbar, avoid file bloat |
| Per-story AI config | Config is global, not per-story |
