# Plan 15.4: Failure-Injection Regression Harness

## Goal

Add the focused regression coverage needed to keep canonical turn integrity stable after the refactor lands.

## Tasks

1. Add failure-injection or test-double coverage around canonical turn commit, mirror writes, autosave, rollback, and resume/load paths.
2. Build regressions for the highest-value gameplay edges: standard narrative turns, challenge-result follow-ups, combat/crafting summaries, and load-after-failure recovery.
3. Verify that canonical and mirrored persistence stay coherent across success, mirror-only failure, and canonical-write failure cases.
4. Capture the new persistence invariants in tests so future feature phases can build on them without reintroducing turn corruption.

## Verification

- regression coverage reproduces the previously risky partial-write scenarios
- tests distinguish canonical-write failure from mirror-write failure and verify the correct outcome for each
- future persistence changes have a stable integrity harness instead of relying on manual playtesting
