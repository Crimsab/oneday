# Plan 3.2: Full Game Loop, State Changes, Save/Load System, and Load Story Menu

## Objective

Complete the core gameplay loop: player picks a choice or types free action -> context builder -> AI call -> parse response -> apply state_changes to character/world -> update DB -> render. Add save/load system with full state snapshots and autosave every N turns. Implement the "Load Story" menu that lets players continue existing stories.

## must_haves

- Full narrative loop: input -> context -> AI -> parse -> state update -> DB persist -> TUI render (CORE-03)
- Free action input always visible alongside AI-suggested choices (CORE-04)
- State changes from AI responses (`state_changes` field) applied to character stats, world state, location (CORE-03)
- Save system: full snapshot of character + world + session position to `saves/` directory (CORE-05)
- Load system: restore from any save point (CORE-05)
- Autosave every N turns (configurable, default 5) (CORE-06)
- Manual save via a method callable from TUI (wired to /save command in Plan 3.3)
- "Load Story" menu shows existing stories with metadata, selects one to enter narrative view
- Story's `updated_at` and `last_played` updated on each session

Create `internal/engine/state.go` with:

```go
// ApplyStateChanges takes the state_changes map from an AI response
// and applies validated changes to the character and world state.
// Returns a list of changes that were applied (for logging/display).
func ApplyStateChanges(
    changes map[string]interface{},
    char *storage.Character,
    world *storage.WorldState,
) ([]StateChange, error)

// StateChange records a single change that was applied.
type StateChange struct {
    Target string // "character" or "world"
    Field  string // e.g. "vitals.hp.current", "location", "attributes.str"
    Old    interface{}
    New    interface{}
}
```

**ApplyStateChanges logic:**

1. Parse `char.StatsJSON` into `map[string]interface{}`.
2. Walk the `changes` map. Supported keys:
   - `"vitals"` — nested map like `{"hp": {"current": -5}}` means subtract 5 from HP. Apply as delta or absolute based on whether value is prefixed with `+`/`-` (number sign) or is an absolute number. For simplicity in v1: treat all numeric values as **new absolute values**. The AI sets `"vitals": {"hp": {"current": 15}}` to set HP to 15.
   - `"attributes"` — e.g. `{"str": 4}` sets STR to 4.
   - `"secondary"` — e.g. `{"reputation": 5}`.
   - `"location"` — string, update `world.CurrentLocation`.
   - `"inventory_add"` — list of item names to add to character inventory.
   - `"inventory_remove"` — list of item names to remove from character inventory.
   - `"currency"` — absolute value for currency.
3. After applying changes, marshal the modified stats back to `char.StatsJSON`.
4. Update `world.CurrentLocation` if location changed.
5. Record each change in the returned `[]StateChange` slice.
6. Validate: HP cannot go below 0, attributes cannot go below 0.

**Also add** `UpdateCharacterStats(db, char)` and `UpdateWorldState(db, world)` helper methods to `internal/storage/stories.go`:

```go
// UpdateCharacterStats updates only the stats_json and updated_at.
func (db *DB) UpdateCharacterStats(c *Character) error

// UpdateWorldState updates the world state fields.
func (db *DB) UpdateWorldState(ws *WorldState) error
```
</action>

<acceptance_criteria>

- `ApplyStateChanges({"location": "Dark Forest"}, char, world)` updates `world.CurrentLocation`
- HP is clamped to >= 0
- Returns a descriptive `[]StateChange` list
- `UpdateCharacterStats` and `UpdateWorldState` persist to DB
</acceptance_criteria>

Create `internal/engine/save.go` with:

```go
// SaveSnapshot represents a complete game state snapshot.
type SaveSnapshot struct {
    ID           string    `json:"id"`
    StoryID      string    `json:"story_id"`
    Name         string    `json:"name"` // "autosave" or user-given name
    Turn         int       `json:"turn"`
    Chapter      int       `json:"chapter"`
    Location     string    `json:"location"`
    CharacterJSON string   `json:"character_json"`
    WorldStateJSON string  `json:"world_state_json"`
    SessionID    string    `json:"session_id"`
    CreatedAt    time.Time `json:"created_at"`
}

// SaveGame creates a full state snapshot to disk and DB.
func SaveGame(db *storage.DB, dataDir string, story *storage.Story, char *storage.Character, world *storage.WorldState, sessionID string, saveName string) (*SaveSnapshot, error)

// LoadGame restores game state from a save snapshot.
// Returns the restored character and world state (caller must update narrator).
func LoadGame(db *storage.DB, dataDir string, saveID string) (*storage.Character, *storage.WorldState, error)

// ListSaves returns all saves for a story, most recent first.
func ListSaves(db *storage.DB, storyID string) ([]SaveSnapshot, error)

// Autosave creates a save named "autosave" (overwrites previous autosave).
func Autosave(db *storage.DB, dataDir string, story *storage.Story, char *storage.Character, world *storage.WorldState, sessionID string) error
```

**SaveGame behavior:**
1. Generate save ID (`uuid.New()`).
2. Serialize character and world state to JSON.
3. Write snapshot to `{dataDir}/stories/{storyID}/saves/{saveID}.json`.
4. Insert row into `saves` DB table (new table — see migration below).
5. Return the snapshot.

**LoadGame behavior:**
1. Read snapshot from DB by save ID.
2. Deserialize character and world state JSON.
3. Update character and world state in DB with the restored values.
4. Return the restored objects.

**Autosave behavior:**
1. Check if an "autosave" save exists for this story.
2. If yes, overwrite it (delete old, create new).
3. If no, create new.

**New migration** (add to `migrations.go` as migration v2):

```sql
CREATE TABLE IF NOT EXISTS saves (
    id TEXT PRIMARY KEY,
    story_id TEXT NOT NULL REFERENCES stories(id) ON DELETE CASCADE,
    name TEXT NOT NULL DEFAULT 'autosave',
    turn INTEGER NOT NULL,
    chapter INTEGER NOT NULL,
    location TEXT NOT NULL DEFAULT '',
    character_json TEXT NOT NULL,
    world_state_json TEXT NOT NULL,
    session_id TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_saves_story ON saves(story_id);
```

Also create `internal/storage/saves.go` with DB CRUD:

```go
func (db *DB) CreateSave(s *SaveSnapshot) error
func (db *DB) GetSave(id string) (*SaveSnapshot, error)
func (db *DB) ListSaves(storyID string) ([]SaveSnapshot, error)
func (db *DB) DeleteSave(id string) error
func (db *DB) GetAutosave(storyID string) (*SaveSnapshot, error)
```
