# Plan 20.3: Investigation Board UX and Codex Integration

## Goal

Expose the investigation board through codex-style browsing so players can reason about mysteries without leaving the story flow or reading giant text dumps.

## Tasks

1. Design the board browsing flow, including filtering by mystery, suspect, clue type, or unresolved contradiction.
2. Reuse codex/dossier interaction patterns so investigation browsing feels native to the current UI language.
3. Surface uncertainty, confidence, and contradiction clearly without implying the board is always correct.
4. Add coverage for empty-state, early-game, and partially discovered mystery flows.

## Verification

- players can inspect mysteries as structured knowledge instead of long prose overlays
- investigation browsing feels consistent with codex/dossier surfaces
- uncertain and contradictory evidence remains clearly presented
