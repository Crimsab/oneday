# Support

Use [GitHub Issues](https://github.com/Crimsab/oneday/issues) for reproducible
bugs and documentation gaps. Use Discussions once they are enabled for setup
questions, story design, and general ideas.

Before opening an issue:

1. Read [Getting started](docs/getting-started.md) and
   [Troubleshooting](docs/troubleshooting.md).
2. Run `oneday doctor --json` and `oneday config show --safe`.
3. Confirm the issue still exists on the latest release.

Attach only sanitized diagnostics. Never post `.env`, `config.yaml`, Codex or
Claude authentication files, provider keys, databases, or private story content.

Potential vulnerabilities belong in a
[private security advisory](https://github.com/Crimsab/oneday/security/advisories/new),
not a public issue.
