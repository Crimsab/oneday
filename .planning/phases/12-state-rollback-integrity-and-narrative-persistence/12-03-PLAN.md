# Plan 12.3: Command Routing, Provider Decoupling, and Save Hygiene

## Goal

Close the remaining command/configuration gaps that break promised functionality or hide degraded behavior.

## Tasks

1. Register `/craft` and `/crafting` in the command parser so the documented flow is actually reachable.
2. Make autosave replacement delete both the DB row and the orphaned snapshot file.
3. Pick the first enabled embedding-capable provider from config instead of hard-requiring LiteLLM, and warn when RAG cannot be built because no embedding provider exists.
4. Send combat/crafting system prompts with the proper `system` role.
5. Add focused regression tests for save rollback, command parsing, migration coverage, and provider selection behavior.

## Verification

- `/craft` no longer falls through to unknown-command handling
- replacing autosave does not leave stale JSON snapshots behind
- OpenRouter can back embeddings when LiteLLM is disabled
- combat and crafting prompt scaffolding uses `system` role messages
- targeted regression tests cover the new rollback and persistence guarantees
