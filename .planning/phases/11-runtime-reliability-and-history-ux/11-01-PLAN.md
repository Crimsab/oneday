# Plan 11.1: Runtime Reliability and Turn Flow

## Goal

Fix the runtime behaviors that actively break immersion or cause user-visible failures during play.

## Tasks

1. Make the typewriter ANSI-safe so rendered styling never leaks raw escape sequences mid-animation.
2. Stop replaying the full accumulated styled history on every turn; only animate the newly added scene content and keep previous history stable.
3. Gate choice/input visibility until the current visible scene playback is ready, so choices never appear “before” the text finishes.
4. Add a lightweight confirmation/prelude for active challenge/minigame flows before the event UI starts.
5. Add local validation for story-definition responses and a retry/repair loop before surfacing bootstrap failure to the player.
6. Add focused tests for typewriter parsing and story-definition validation/retry behavior.

## Verification

- live turns never show raw ANSI escape sequences during playback
- old history remains stable while only new scene text animates
- choices do not appear before the scene has visibly settled
- active dice/minigame challenges show a clear prelude/confirm step
- invalid story JSON triggers retry/repair before the UI shows a hard error
