# Plan 4.2: Enhanced Character Sheet, Inventory Views, and NPC Context Injection

## Objective

Build polished TUI views for the character sheet (/stats) and inventory (/inventory) that properly display skills with levels/XP, traits, titles, and relationships. Inject relevant NPC data into the AI context so the AI maintains consistent NPC behavior across turns. After this plan, the player can inspect their full character progression and the AI has access to NPC personality, disposition, and private thoughts when generating responses.

## must_haves

- /stats overlay shows: name, background, vitals (with bars), attributes (labeled from schema), secondary stats, traits, skills with level + XP progress, titles, and known NPC relationships (name + disposition)
- /inventory overlay shows: equipped items, backpack items (with type icons), quest items, currency (with name from schema)
- Context builder injects relevant NPC data into AI prompts (NPCs seen in last N turns)
- Narrator passes NPC context string to the system prompt builder
- Attribute labels come from the story's stats_schema (not hardcoded key names)
- Skills display shows "Lockpicking Lv.3 (45/300 XP)" format
- Disposition shown as a word: Hostile/Unfriendly/Neutral/Friendly/Allied based on value ranges

### Task 5: Add NPC last_seen_turn update on mention

<read_first>
- internal/engine/narrator.go (sendTurn — after AI response)
- internal/storage/npcs.go (ListNPCs, UpdateNPC)
</read_first>

<action>
After the AI generates a response and state changes are applied, scan the narrative text for known NPC names and update their `last_seen_turn`. This keeps the NPC context window fresh.

Create a helper in `npc.go`:
```go
// UpdateNPCLastSeen checks the narrative text for mentions of known NPCs
// and updates their last_seen_turn. Case-insensitive substring match on first name
// and full name.
func UpdateNPCLastSeen(db *storage.DB, storyID string, narrativeText string, currentTurn int) error
```

Logic:
1. `db.ListNPCs(storyID)` to get all NPCs
2. For each NPC, check if their name (or first name) appears in `narrativeText` (case-insensitive)
3. If found, update `last_seen_turn` to `currentTurn`
4. Batch the updates (single query per NPC, or a helper that does UPDATE WHERE name IN (...))

Call this in `sendTurn` after state changes are applied:
```go
if narrative.Narrative != "" {
    _ = UpdateNPCLastSeen(n.db, n.story.ID, narrative.Narrative, n.session.Turn())
}
```

This is best-effort — errors are swallowed. The AI can also explicitly update NPCs via state_changes, this is just a safety net.
</action>

<acceptance_criteria>
- NPC `last_seen_turn` is updated when their name appears in the narrative
- Both full name ("Lyanna Ashford") and first name ("Lyanna") trigger the update
- Matching is case-insensitive
- Function is called after every AI response
- Errors don't break the game flow (non-fatal)
- NPCs not mentioned are not updated (their last_seen_turn stays as-is)
</acceptance_criteria>
